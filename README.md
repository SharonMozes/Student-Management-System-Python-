Student Management System (Python)
A simple console-based Student Management System built in Python that allows you to add, view, search, update, and delete student records, with data persistence using CSV files.

Features
Add a new student (Roll No, Name, Marks).

View all student records.

Search for a student by Roll Number.

Update student details (Name or Marks).

Delete a student record.

Automatically save all data to a CSV file (students.csv).

Load data from the CSV file when the program starts.

Tech Stack
Language: Python 3

Concepts Used:

Object-Oriented Programming (OOP)

Lists & Loops

File Handling (CSV)

Menu-driven Console Interface

Conditional Logic (if-else)
